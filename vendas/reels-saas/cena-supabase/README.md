# Cena Supabase para Reels

Cena vertical de 8,4 segundos em 1080x1920.

Fluxo mostrado: Table Editor com PostgreSQL, Authentication, Storage e API Docs.

## Prévia

Abra `index.html` no navegador. A animação reinicia automaticamente.

## Renderizar

```powershell
python render.py
```

O arquivo será salvo como `cena-supabase.mp4`.

Os nomes, e-mails e métricas exibidos são dados fictícios criados apenas para a demonstração visual.
