# Cena Vercel DNS para Reels

Cena vertical de 6,6 segundos em 1080x1920.

Fluxo mostrado: Domains, seleção do domínio, DNS Records, registro A, preenchimento dos campos e confirmação.

## Prévia

Abra `index.html` no navegador. A animação reinicia automaticamente.

## Renderizar

```powershell
python render.py
```

O arquivo será salvo como `cena-vercel-dns.mp4`.

O valor `76.76.21.21` é o endereço geral documentado pela Vercel para registros A. Em um projeto real, confirme o valor recomendado no painel do próprio domínio.
