# Cena mobile da Ah Imobiliária

Take vertical de 15 segundos para Reels, em 1080 × 1920 e 30 fps.

O vídeo mostra:

- página inicial real em viewport mobile, com scroll;
- conversa digitada no atendimento virtual;
- recomendação do Orizon Rooftop;
- entrada no painel do corretor;
- lista de imóveis, indicadores, CRM e funil;
- ficha de um lead com histórico de conversa.

Os dados usados na gravação são fictícios e ficam no IndexedDB temporário do navegador de renderização. Nenhuma credencial real aparece.

## Renderizar

```powershell
python render.py
```

Para revisar apenas quadros importantes:

```powershell
python render.py --stills
```
